## Задание 1. Объектная модель данных

### Задача 4. Дроби
* **Текст задачи:** Разработать неизменяемый класс `Fraction` (Дробь), хранящий числитель и знаменатель. Реализовать операции сложения, вычитания, умножения и деления дробей, а также аналогичные операции с целыми числами. Обеспечить корректное хранение знака и валидацию знаменателя (запрет деления на ноль).
* **Алгоритм решения:** Сделал поля числителя и знаменателя `private final`, чтобы их нельзя было изменить после создания объекта. В конструкторе написал проверку: если знаменатель равен `0`, программа выдает ошибку `IllegalArgumentException`. Там же сделал обработку знаков: если знаменатель с минусом, то минус переносится наверх в числитель. Все математические методы считают результат по формулам и возвращают новую дробь. Чтобы можно было складывать или вычитать дробь с обычным целым числом, сделал перегрузку методов (написал одинаковые методы, но которые принимают `int value`).

### Задача 7. Непустые имена
* **Текст задачи:** Модифицировать класс `Name` (Имя) из предыдущих работ, сделав его неизменяемым. Добавить валидацию входных данных в конструктор: объект не может быть создан, если все его параметры (фамилия, имя, отчество) являются пустыми строками или равны `null`.
* **Алгоритм решения:** Сделал все поля строк `final`, чтобы объект стал неизменяемым. В главном конструкторе написал проверку через `if`. Написал свой метод `isValid`, который проверяет, что строка не `null` и не состоит из одних пробелов (использовал `.trim().isEmpty()`). Если имя, фамилия и отчество одновременно оказались пустыми, конструктор выдает ошибку. В методе `toString()` использовал `StringBuilder` и через `if` проверяю каждое поле: если оно заполнено, то добавляю его в общую строку, а если пустое — просто пропускаю.


## Задание 2. Разработка структур данных

### Задача 2. Секреты
* **Текст задачи:** Создать структуру данных `Secret` для цепочки передачи информации. Объект хранит текст секрета и владельца. Прямой доступ к тексту закрыт. Текст раскрывается в консоль только в момент передачи новому владельцу, при этом информация искажается (добавляется до 10% случайных символов). Объект можно передать только один раз. Реализовать методы анализа цепочки.
* **Алгоритм решения:** Сделал класс в виде двусвязного списка, где каждый секрет знает своего предыдущего и следующего человека (поля `previous` и `next`). Геттер для текста делать не стал, чтобы никто не мог просто так прочитать секрет. Написал конструктор передачи секрета: он берет старый секрет, печатает его текст на экран (как просили в задании) и ставит флаг `isTold = true`. Если попытаться передать этот секрет еще раз, программа выдаст ошибку. Текст для нового человека зашумляется в методе `distortText`: через `Random` берется случайное число от 0 до 10% от длины строки, и в цикле в случайные места текста вставляются левые символы. Методы поиска ходят по ссылкам `next` и `previous` вперед и назад по цепочке.

## Задание 4. Полиморфизм

### Задача 2. Дробь это число
* **Текст задачи:** Интегрировать класс `Fraction` в стандартную иерархию числовых типов Java. Класс должен стать подтипом абстрактного числового класса.
* **Алгоритм решения:** Написал в заголовке класса `extends Number`. Из-за этого Java заставила меня обязательно добавить внутрь четыре стандартных метода: `intValue()`, `longValue()`, `floatValue()` и `doubleValue()`. Внутри них я просто делю числитель на знаменатель. Перед делением обязательно пишу приведение типов, например `(double)`, чтобы Java считала с точкой, а не округляла результат до целого числа.


## Задание 5. Полиморфизм

### Задача 1. Сложение чисел
* **Текст задачи:** Написать статический метод, который принимает произвольный набор любых чисел и возвращает сумму их вещественных значений.
* **Алгоритм решения:** Создал отдельный класс `MathUtils` и написал там метод `sumAllNumbers`. Чтобы метод мог принимать сколько угодно чисел, использовал троеточие (`Number... numbers`). Внутри написал цикл, который перебирает все эти числа и складывает их в общую переменную. Так как наша дробь теперь наследуется от `Number`, метод спокойно принимает и складывает в одну кучу обычные `int`, `double` и наши дроби `Fraction`, вызывая у всех метод `.doubleValue()`.


## Задание 6. Интерфейсы

### Задача 1. Сравнение дробей
* **Текст задачи:** Обеспечить возможность сравнения объектов класса `Fraction` между собой с использованием стандартных интерфейсов Java.
* **Алгоритм решения:** Добавил к классу дроби `implements Comparable<Fraction>`. Написал обязательный метод `compareTo`. Чтобы сравнение было супер-точным и не ломалось из-за округления double, я складываю дроби по правилу пропорции (крест-накрест): числитель первой умножаю на знаменатель второй, и наоборот. Полученные большие числа сравниваю через стандартный метод `Long.compare()`.
