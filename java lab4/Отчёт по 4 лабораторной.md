## Задание 1. Обобщенные типы

### Задача 1: Обобщенная коробка
#### Текст задачи
Создайте сущность Коробка, которая обладает следующими характеристиками:
* Может хранить один произвольный объект в один момент времени.
* Объект можно получить и разместить на хранение в любой момент времени.
* Если объект забирают из коробки – ссылку на этот объект необходимо обнулить.
* Если объект кладут в коробку, но она не пуста – необходимо выкинуть исключение.
* Имеет метод проверки на заполненность.
* Методы класса должны работать с тем типом данных, который был указан во время создания объекта.

Создайте Коробку, которая может хранить целочисленное значение, разместите туда число 3. Передайте Коробку в какой-либо метод, извлеките значение, и выведите его на экран.

#### Алгоритм решения
Класс `Box<T>` параметризуется типом `T`. Внутри структуры объявлено приватное поле для хранения ссылки на один объект. Метод помещения объекта проверяет состояние коробки с помощью логического метода `isEmpty`. Если поле не равно `null`, выбрасывается исключение `IllegalStateException`, сигнализирующее о заполнении. Метод извлечения сохраняет ссылку во временную переменную, обнуляет исходное поле класса для предотвращения утечек данных и возвращает объект пользователю. Для демонстрации работы в утилитарном классе реализован обобщенный метод, который принимает коробку, вызывает её метод извлечения и выводит результат на экран консоли.


### Задача 3: Сравнимое
#### Текст задачи
Создайте ссылочный тип Сравнимое, гарантирующий наличие по данной ссылке метода со следующими характеристиками:
* Называется “сравнить”
* Принимает объект.
* Тип принимаемого объекта может быть изменен без изменения самого Сравнимого.
* Возвращает целое число.

#### Алгоритм решения
Создан обобщенный интерфейс `ComparableCustom<T>`, описывающий контракт для сравнения объектов. Он параметризуется типом `T`, что позволяет менять тип принимаемого аргумента без изменения структуры самого интерфейса. Контракт включает метод `compare(T other)`, возвращающий целое число. Для практической проверки разработан класс `StringLengthComparable`, который имплементирует данный интерфейс для типа `String`. Логика сравнения базируется на сопоставлении длин строк с использованием встроенного метода `Integer.compare`.


## Задание 2. Параметризации

### Задача 2: Поиск максимума
#### Текст задачи
Создайте метод, принимающий набор Коробок из задачи 3.1.1 и возвращающий максимальное из их значений в формате double. Принимаемые методом Коробки могут быть параметризованы любыми видами чисел.

#### Алгоритм решения
В утилитарном классе разработан статический метод `findMax`. В качестве входного аргумента метод принимает список коробок. Чтобы обеспечить совместимость с коробками, содержащими любые типы числовых данных (такие как `Integer`, `Double`, `Float`), сигнатура метода использует маску типа с верхней границей: `List<Box<? extends Number>>`. Внутри метода организован цикл, который обходит коллекцию, проверяет коробки на пустоту и извлекает числовые значения без полной очистки контейнера с помощью метода просмотра. Каждое значение приводится к типу `double` через вызов метода `doubleValue()` суперкласса `Number`. Метод сравнивает элементы и возвращает максимальное число.


## Задание 3. Обобщенные методы

### Реализация инфраструктуры обработки данных
Для выполнения задач трансформации, фильтрации и сокращения данных был спроектирован базовый класс `GeneralMethods`. Он содержит обобщенные статические методы обработки списков и соответствующие им функциональные интерфейсы (`Transformer`, `Condition`, `Combiner`), выступающие в роли контрактов для реализации конкретного поведения.


### Задача 1: Функция
#### Текст задачи
Разработайте метод, который будет принимать список значений типа T, и объект имеющий единственный метод apply. Данный метод надо применить к каждому элементу списка, и вернуть новый список значений типа P, при этом типы T и P могут совпадать, а могут не совпадать.
Примеры применения:
1. Передача списка строк, получение их длин.
2. Передача списка чисел, преобразование отрицательных в положительные.
3. Передача списка массивов целых чисел, нахождение максимумов.

#### Алгоритм решения
Метод `transform` параметризован типами `T` (исходный) и `P` (результирующий). Метод принимает коллекцию `List<T>` и объект интерфейса `Transformer<T, P>`. Внутри создается новый пустой `ArrayList<P>`. С помощью цикла "for-each" последовательно перебираются все элементы исходного списка. К каждому элементу применяется метод `apply`, а полученный результат типа `P` помещается в новую коллекцию, которая возвращается по завершении работы. Конкретные правила преобразования (вычисление длины строки, взятие модуля числа, поиск максимума в массиве) вынесены в отдельные классы-реализаторы.


### Задача 2: Фильтр
#### Текст задачи
Разработайте метод, который будет принимать список значений типа T и объект имеющий единственный метод test (принимает T и возвращает boolean). Верните новый список типа T, из которого удалены все значения не прошедшие проверку условием.
Примеры применения:
1. Фильтрация строк, имеющих менее трех символов.
2. Фильтрация положительных элементов.
3. Фильтрация массивов, в которых нет ни одного положительного элемента.

#### Алгоритм решения
Метод `filter` оперирует обобщенным типом `T`. Он принимает `List<T>` и объект интерфейса `Condition<T>`. Внутри создается результирующий список. Метод итеративно просматривает входные данные и для каждого элемента вызывает предикат `test(item)`. Если предикат возвращает значение `true`, элемент признается прошедшим фильтрацию и добавляется в выходной список. Элементы, вернувшие `false`, игнорируются. Критерии отбора реализованы через специализированные классы.


### Задача 3: Сокращение
#### Текст задачи
Разработайте метод, который будет принимать список значений типа T и способ с помощью которого список значений можно свести к одному значению типа T, которое и возвращается из метода. Измените разработанный метод таким образом, чтобы данный метод гарантированно не возвращал null и не выбрасывал ошибок в том случае, если исходный список пуст.
Примеры применения:
1. Конкатенация списка строк в одну большую строку.
2. Суммирование списка чисел.
3. Подсчет общего количества элементов в списке списков.

#### Алгоритм решения
Обобщенный метод `reduce` принимает список данных `List<T>`, объект `Combiner<T>` и значение по умолчанию `defaultValue`. Первым этапом выполняется проверка входного списка на равенство `null` или на отсутствие элементов. Если условие истинно, метод сразу же возвращает переданный `defaultValue`, предотвращая падение программы или возврат нежелательного `null`. Если список содержит данные, то в качестве стартового аккумулятора берется первый элемент коллекции (индекс `0`). Далее запускается цикл со второго элемента (индекс `1`), где на каждом шаге текущий аккумулятор и очередной элемент списка объединяются через метод `combine`, перезаписывая значение аккумулятора. По окончании цикла возвращается итоговый агрегированный объект.
